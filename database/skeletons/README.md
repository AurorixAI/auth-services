# Скелеты навыков по классам (L1–L4)

## Структура

Каждый файл содержит полную иерархию навыков одного класса:

| Файл | Класс | Статус |
|------|-------|--------|
| `grade_05.sql` | 5 класс | ✅ Готов (~130 L4) |
| `grade_06.sql` | 6 класс | ✅ Готов (34 L4, 45 prereqs) |
| `grade_07.sql` | 7 класс | 🔲 Шаблон |
| `grade_08.sql` | 8 класс | 🔲 Шаблон |
| `grade_09.sql` | 9 класс | 🔲 Шаблон |
| `grade_10.sql` | 10 класс | 🔲 Шаблон |
| `grade_11.sql` | 11 класс | 🔲 Шаблон |

## Конвенции ID

| Уровень | Формат ID | Пример | Описание |
|---------|-----------|--------|----------|
| L1 | `G{класс}_{РАЗДЕЛ}` | `G6_ALG` | Раздел (Алгебра, Геометрия, ...) |
| L2 | `G{класс}_T{NN}` | `G6_T01` | Тема (порядковый номер в классе) |
| L3 | `G{класс}_P{NN}` | `G6_P01` | Пункт/Параграф |
| L4 | `G{класс}_S{NN}_{код}` | `G6_S01_add_neg` | Атомарный навык |

- **Префикс обязателен**: `G5_`, `G6_`, ..., `G11_`
- **L4 ID**: `G{класс}_S{порядок_пункта}_{snake_case_описание}`
- **Максимум 30 символов** для ID

## Поля

```sql
INSERT INTO knowledge_hierarchy (
  id,                  -- G6_T01  (до 30 символов)
  level,               -- L1 | L2 | L3 | L4
  parent_id,           -- ссылка на родителя (NULL для L1)
  name,                -- English name
  name_ru,             -- Русское название
  description,         -- Описание (опционально)
  class_level_start,   -- Начальный класс (обычно = текущий)
  class_level_end,     -- Конечный класс (= текущий, или выше если тема повторяется)
  importance,          -- 1-10 (10 = ключевой навык)
  sequence_order       -- Порядок внутри родителя
)
```

### Дополнительные поля для L4

```sql
  cognitive_type,      -- recall | apply | analyze | evaluate | create
  typical_time_seconds -- Среднее время на задачу (секунды)
```

## Кросс-классовые темы

Если тема из 5 класса **повторяется** в 6 классе:

1. **НЕ дублировать** навык — расширить `class_level_end` у существующего
2. Или создать **навык-ссылку** в 6 классе через `skill_prerequisites`:
   ```sql
   INSERT INTO skill_prerequisites (skill_id, prerequisite_id, relation_type)
   VALUES ('G6_S01_xxx', 'G5_S01_yyy', 'extends');
   ```

## Как заполнять

1. Взять PDF методиста / учебник для класса
2. Выделить разделы (L1), темы (L2), пункты (L3)
3. Разбить каждый пункт на атомарные навыки (L4)
4. Проверить: один L4 = один вопрос на экзамене
5. Установить `importance` и `cognitive_type`
6. Добавить `skill_prerequisites` (предпосылки из предыдущих классов)
